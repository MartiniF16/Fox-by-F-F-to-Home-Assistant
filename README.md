Code for adding the FOX energy meter from F&F to the Home Assistant program.
For individual devices, the API can be found on the manufacturer's website http://fox-updater.fhome.pl/rest_api_doc/ (Rest API Fox Energy).
The device's IP address must be changed.
A fix has been applied to ignore anomalies. 

Kod dodania licznika energii FOX firmy F&F do programu Home Assistant
Dla poszczególnych urządzeń API można znaleźć na stronie producenta http://fox-updater.fhome.pl/rest_api_doc/ (Rest API Fox Energy)
Należy zmienić IP urządzenia. 
Zastosowano poprawkę, by ignorował anomalie.
